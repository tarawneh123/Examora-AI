# منصة الاختبارات التعليمية (الإصدار الإنتاجي الشامل) - Abla Exam AI

منصة تعليمية متكاملة واحترافية مخصصة للمعلمين والطلاب، تركز على إدارة وتنسيق الامتحانات المدرسية وفق المعايير الرسمية المعتمدة في المملكة الأردنية الهاشمية ووزارة التربية والتعليم.

---

## 🌟 أبرز مميزات النظام المطور

1. **إدارة المواد ككيان مستقل (Subject Domain Entity):**
   - المواد الدراسية أصبحت كياناً برمجياً وقاعدة بيانات موحدة (Canonical Entity).
   - تضم المواد الأساسية الافتراضية: اللغة العربية، اللغة الإنجليزية، تاريخ الأردن، والتربية الإسلامية، مع إمكانية إضافة مواد مخصصة لا نهائية.
   - ضبط تلقائي لاتجاه الواجهة (RTL/LTR) ومفاتيح الإجابة (أ-د أو A-D) حسب المادة.

2. **حزم الأسئلة والوحدات (Question Packages):**
   - تنظيم المنهاج ضمن حزم ووحدات مستقلة تتبع المادة الدراسية، مع منع تكرار أسماء الحزم داخل نفس المادة.

3. **محرك الاستخراج الذكي (OSR - Optical Structured Recognition):**
   - محرك رسمي موحد يدعم استخراج الأسئلة من الصور والملفات والنصوص.
   - ذكاء متقدم في استخراج خيارات الأسئلة الإنجليزية والأفقية والمتعددة الأعمدة.
   - منع الأخطاء الشائعة (مثل تفسير الكلمات الإنجليزية الشائعة مثل `All` أو `Could` أو `About` كخيارات).
   - الأسئلة المستخرجة تدخل أولاً بحالة `NEEDS_REVIEW` لضبط الجودة.

4. **مركز مراجعة الأسئلة وضبط الجودة (QC Review Center):**
   - مراجعة دقيقة لكل سؤال مستخرج، والخيارات، ونسبة الدقة (Confidence %)، وتنبيهات الجودة.
   - إجراءات فردية وجماعية (اعتماد المحدد، رفض المحدد، تعديل، حذف) دون اعتماد جماعي عشوائي.

5. **منشئ الامتحانات الذكي (Exam Creator):**
   - حساب تلقائي ودقيق لعدد الأسئلة دون إجبار المعلم على الكتابة اليدوية.
   - إفصاح تدريجي (Progressive Filtering) لعرض الأسئلة التابعة لنفس المادة والحزمة فقط.
   - منع خلط أسئلة من مواد دراسية مختلفة في الامتحان الواحد.
   - حماية الامتحان بكلمة مرور مشفرة اختيارياً.

6. **إدارة الامتحانات ومتابعة الطلاب (Exam Management Hub):**
   - مركز شامل لكل امتحان يعرض: بيانات الامتحان، الأسئلة، مفاتيح النشر، قائمة الطلاب المتقدمين مع أحدث حالة وعلامة وتاريخ، وزر عرض النتيجة.
   - حذف آمن للمعاملات (Transactional Delete): حذف الامتحان وسجلاته ومحاولاته مع الحماية التامة لأسئلة بنك الأسئلة دون مساس.
   - نسخ الامتحان دون نسخ سجلات الطلاب أو النتائج السابقة.

7. **نموذج المحاولات واللقطة الثابتة غير القابلة للتغيير (Immutable Snapshots):**
   - فور بدء الطالب للامتحان، يتم أخذ لقطة مجمدة كاملة (Snapshot) لنصوص الأسئلة وخياراتها وعلاماتها.
   - أي تعديل لاحق على بنك الأسئلة أو مفاتيح الإجابة **لا يغير أبداً** المحاولات السابقة أو النتائج المعتمدة.
   - حفظ تلقائي مستمر (Debounced Autosave) مع مؤشر فوري (جارِ الحفظ / تم الحفظ ✓ / إعادة المحاولة ⚠️).
   - استكمال المحاولة النشطة (Resume)، والتوجيه التلقائي لكشف النتيجة في حال تم تسليم الامتحان (منع إعادة الدخول).

8. **الطباعة الرسمية وتصدير PDF (A4 Portrait Standards):**
   - ترويسة وزارية رسمية تظهر حصرياً في الصفحة الأولى (Page 1 Only).
   - تبدأ أسئلة الصفحة الثانية والأخيرة مباشرة من أعلى الصفحة بدون أي فراغ محجوز غير مبرر (Zero Blank Header Gap).
   - في امتحانات اللغة الإنجليزية: ترويسة الامتحان تبقى باللغة العربية (RTL) دون تكسر الحروف، وأسئلة الامتحان تظهر بالإنجليزية (LTR).
   - إخفاء جميع الأزرار وشريط التنقل والمؤقتات في الطباعة.

9. **تجربة مستخدم هادئة وخالية من الإزعاج (Zero Toast Spam):**
   - الاستغناء عن نوافذ التنبيه المنبثقة المتكررة واستبدالها بحالات حالة مضمنة، وبطاقات تحديث العدادات، وتأكيدات بصرية داخل الشاشة.

10. **الأمان والعزل التام بين السياقات:**
    - عزل كامل بين جلسات المعلمة وجلسات الطلاب.
    - حماية ضد الوصول غير المصرح (IDOR Prevention): لا يمكن لأي طالب استعراض نتائج أو أوراق طلاب آخرين.

## 🚀 دليل التشغيل والتثبيت

### المتطلبات الأساسية
- بيئة بايثون (Python 3.10+).
- المكتبات الموصى بها في `requirements.txt`:
  ```bash
  pip install -r requirements.txt
  ```

*(ملاحظة: المنصة مزودة أيضاً بطبقة تشغيل داخلية ذاتية الاحتواء `mini_flask.py` تمكنها من العمل في بيئات العمل المعزولة ومحطات التقييم دون الحاجة إلى اتصال خارجي).*

### تشغيل المنصة
```bash
python app.py
```
- **لوحة تحكم المعلمة:** `http://127.0.0.1:8765/`
- **بوابة دخول الطلاب:** `http://127.0.0.1:8765/student`

### تشغيل الاختبارات الآلية
```bash
python -m unittest discover -s tests -p "test_*.py"
```
